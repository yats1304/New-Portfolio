# [Yatish Chaubal — Full Stack Developer Portfolio](https://www.yatishchaubal.online/)

A personal portfolio built from scratch using **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS v4** — with a zero-re-render animation system powered by [React Zero UI](https://github.com/react-zero-ui/core).

This project is both a showcase of my work and a technical playground. The goal was to build something that performs well, feels premium, and proves that you don't need a no-code tool to achieve great design.

---

## Tech Stack

- **Framework** — Next.js 16 (App Router, React Server Components)
- **UI** — React 19, Tailwind CSS v4, Motion (Framer Motion)
- **State / Animation** — React Zero UI (zero re-render state management)
- **Language** — TypeScript
- **Testing** — Playwright
- **Deployment** — Vercel

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
